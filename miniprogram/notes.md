## 🗄️ 云数据库表设计

### 1. piratecat_notes_user（用户表）
| 字段名 | 类型 | 说明 |
|--------|------|------|
| nickName | String | 用户昵称 |
| avatarUrl | String | 用户头像 |
| createdAt | Date | 创建时间 |
| updatedAt | Date | 更新时间 |

### 2. piratecat_notes_todo（事项表）
| 字段名 | 类型 | 说明 |
|--------|------|------|
| content | String | 事项标题 |
| description | String | 事项详细描述 |
| remindAt | Date | 提醒时间 |
| status | String | 事项状态 |
| statusWarnMsg | String | 状态警告信息 |
| color | number | 提醒颜色 |
| creatorOpenID | String | 创建者openid（关联User表） |
| createdAt | Date | 创建时间 |
| updatedAt | Date | 更新时间 |

用户启动流程：
    用户启动，检查piratecat_notes_user表，存在则读取，不存在则创建一行空数据。
用户创建事项流程：
    用户A填写对应信息，piratecat_notes_todo表新增一行

## 📨 订阅消息模板

### 日程提醒模板
- **模板ID**: `IiYABIcxdWwaAbqXPb71Yijw-iYMRlbRpghZCT58eQ8`
- **模板内容**:
  - 提醒内容: `{{thing2.DATA}}`
  - 日程时间: `{{date4.DATA}}`
  - 参加人: `{{thing24.DATA}}`
  - 备注: `{{thing11.DATA}}`

样式描述：
底部Tab：待办、我的
待办：
1. 展示所有的待办事项列表（一个Cell展示待办内容，左侧是一个勾选框用来表示是否完成），从上到下按：临近时间、创建时间、是否完成排序，待办事项彩色、完成事项置灰
2. 点击一个事项，进入事项管理页，可以管理待办内容、描述、提醒时间、外部颜色、关联人
3. 点击创建按钮，插入一个创建事项Cell
4. 点击查找，则在所有的事项中搜索相关事项并进入事项管理页
我的：
1. 顶部是个人信息区域：头像、名字、背景图等
2. 下面是按钮区域：编辑个人信息、关于我们、订阅类型管理等
